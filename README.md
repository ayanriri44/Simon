# 🎮 Simon Game

A browser-based memory game inspired by the classic Simon toy. Watch the sequence of flashing colors, then repeat it in the same order. Each round adds one more step, so how far can you go?

**🔗 Live demo:** https://simon-jxbo.onrender.com/

## ✨ Features

- Random color sequence that grows by one step every level
- Flash animations to show the pattern
- Click detection with visual press feedback
- Level tracking and a game-over state
- Restart by pressing any key, and play again instantly
- Simple, responsive layout

## 🕹️ How to Play

1. Press any key to start the game.
2. Watch the sequence of colored buttons that flash.
3. Click the buttons in the same order.
4. If you get it right, the next level adds one more step.
5. One wrong click ends the game. Press any key to try again.
